## Findings considered and rejected

- Public support card data in `src/config/support.ts` (and the structural test
  that pins it): owner-published by an explicit decision in `docs/DESIGN.md`
  (2026-10-10). It is intended to be visible on the site; not treated as a
  leaked credential. Do not copy the value into new docs.
- Empty `PRODUCT.md` / `ARCHITECTURE.md` / `PLAN.md` shells: earlier batch
  rejected backfilling while `DESIGN.md` carries the decisions. Batch 2 keeps
  that decision; plan 017 does not touch those files.
- Empty `lint` script (`echo` stub): ESLint setup is not worth it for a static
  slice; `astro check` is the real gate.
- Vazirmatn subset (~200KB in `dist/_astro/`): within the design budget; no
  action. The 500-weight import is unused by current classes, but the browser
  does not download an unused face and the CSS cost is negligible.
- `window.__drBound` inline script, `color-mix` usage, `rel=noopener` coverage,
  zod URL validation on content links: reviewed, sound.
- Security sweep (static output, no backend/auth/forms, `npm audit` clean, no
  secrets in the tree): no findings; not planned.
- Schema-level travel `imageAlt` enforcement: rejected in favor of the
  test-layer guard (plan 007).
- A test asserting "all project images are webp": over-constrains future
  uploads (plan 008 notes why).
- Auto-generating QA detail routes from the content dir: deferred; five stable
  slugs do not justify the indirection.
- GitHub Actions pinned by mutable tags (`actions/checkout@v4` etc.): these are
  first-party actions; the supply-chain risk is low for a static personal
  site. Revisit if a third-party action is added.
- Minor dependency lag (Astro 7.3.6 → 7.4.1, `@astrojs/check` 0.9.10 → 0.9.11,
  `playwright-core` 1.63 → 1.64): routine updates, not migrations; `npm audit`
  reports 0 vulnerabilities.
- `ClientRouter` adds ~16KB raw / ~5.7KB gzip beyond the inline script; the
  `~2KB` comment refers to the site's own inline code. Instant navigation is an
  owner-requested, documented tradeoff (`docs/DESIGN.md`); not a finding.
  Correct the comment only if it is touched for another reason.
- Footer copyright year (`© ۱۴۰۵`) is hardcoded: correct for the current SH
  year and trivial to update; not worth a plan.
- `ProfilePhoto` `sizes` over-claims the rendered width on the about page at
  1x DPR; the browser picks the 855w variant. Minor transfer cost, no visual
  impact; fold into the responsive-image quick-fix if it is picked up.
- A 404 route test: the 404 page is built and noindexed; the existing route
  and SEO tests cover the contract.
